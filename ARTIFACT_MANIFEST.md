# Artifact manifest

## Current Stage-1 implementation

- `src/sua_lab/`: backend adapters, prompt construction, metrics, and the stylized theory harness.
- `configs/`: transparent institutional treatment configurations.
- `data/seed_corpus.jsonl`: synthetic, redistributable organizational-science seed environment.
- `scripts/run_demo.py`: deterministic plumbing test.
- `scripts/run_experiment.py`: single configurable live-model run.
- `scripts/run_grid.py`: reproducible configuration-grid runner.
- `tests/test_smoke.py`: basic pipeline and directional theory-harness checks.
- `sample_results/`: deterministic engineering outputs plus raw traces and run metadata.
- `EXPERIMENTS.md`: Stage-2 experimental questions, outcomes, and falsification criteria.
- `BOUNDARIES.md`: claims the artifact can and cannot support.
- `REPRODUCIBILITY.md`: trace, backend, and replayability principles.

## Stage-2 build targets

1. multiple open-weight LLM families and prompt ablations;
2. embedding-based idea overlap and topical-coverage measures;
3. LLM editor/reviewer roles with explicit signal/noise treatments;
4. blinded human ratings of novelty, validity, and similarity;
5. cached trace release and containerized reference runs;
6. interactive institutional-design interface for workshop use.
